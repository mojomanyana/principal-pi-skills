# Technique Selection — What to Reach For

Don't run techniques mechanically. Pick the one that fits the problem shape:

| If the user... | Reach for | Reference |
|----------------|-----------|-----------|
| Opens with a solution, not a problem | 5 Whys, JTBD | [problem-framing.md](problem-framing.md) |
| Has a fuzzy or moving problem | Problem statement template, How Might We | [problem-framing.md](problem-framing.md) |
| Has stale, predictable ideas | SCAMPER, analogies, worst-possible-idea | [divergent-techniques.md](divergent-techniques.md) |
| Is stuck on volume | Crazy 8s, brainwriting (silent generation) | [divergent-techniques.md](divergent-techniques.md) |
| Has cached "best practice" thinking | Lateral provocations, first principles | [divergent-techniques.md](divergent-techniques.md), [problem-framing.md](problem-framing.md) |
| Has too many options and can't choose | ICE/RICE, MoSCoW, impact/effort | [convergent-evaluation.md](convergent-evaluation.md) |
| Is about to commit to something risky | Pre-mortem, reversibility check | [critical-pressure.md](critical-pressure.md), [convergent-evaluation.md](convergent-evaluation.md) |
| Has an idea they're emotionally attached to | Steel-man alternatives, inversion | [critical-pressure.md](critical-pressure.md) |
| Seems to be confirming, not exploring | Six Hats (force black/critical pass), devil's advocate | [critical-pressure.md](critical-pressure.md) |
| Is showing signs of bias (anchoring, sunk cost, etc.) | Name the bias, run the counter-script | [cognitive-biases.md](cognitive-biases.md) |

For session shape itself — when to run the full Diamond vs a short loop, how to facilitate a multi-turn session — see [facilitation-playbook.md](facilitation-playbook.md).
