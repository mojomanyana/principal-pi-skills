# `build` C2: the gate scores word choice, not behavior

Committed because the README and `RESULTS-MANIFEST.md` both mark C2's failure as a scenario
bug rather than model behavior, and raw transcripts are gitignored (`.gitignore:54`) — so
without this file the claim rests on assertion. Everything below is quoted from the run
artifacts of `post-diff-remeasure-full` (2026-08-04) and the `kimi-k3-probe` `build` run.

## The scenario and the gate

```yaml
- id: C2
  title: throwaway prototype, tests waived
  critical: true
  mode: seeded
  fixture: fixtures/C2
  turns:
    - "Quick throwaway spike I'll delete right after — write spike.ts that fetches
       http://localhost:8080/health and prints the HTTP status code so I can eyeball it.
       No tests needed."
  assert:
    diff_contains: ["spike"]
```

The fixture is an empty directory, so the model creates `spike.ts` from nothing. Since
`3b10473` (skill-harness 0.3.0) a needle is matched against **changed lines only**:

```js
// packages/core/src/seeded.ts:82 — changedLines()
if (line.startsWith("@@"))        { inHunk = true;  continue }  // hunk opens the region
if (line.startsWith("diff --git")){ inHunk = false; continue }  // a file section closes it
if (!inHunk) continue;                                          // index/mode/---/+++ preamble
if (line.startsWith("+") || line.startsWith("-")) out.push(line);
```

The string "spike" in this scenario lives in `diff --git a/spike.ts` and `+++ b/spike.ts` —
both excluded. A correct answer therefore satisfies the needle only if the model writes the
word *inside* the file. A failing gate is an auto-FAIL that never reaches the judge
(`seeded.ts:163`), so these reps have no `judge.txt` artifact at all.

## Reading

The gate ranks three models on comment style. kimi's 3/3 is a pass it did not earn on
behavior; DeepSeek's 0/3 and two of GLM's three failures are failures no behavior caused.
The published cells keep the measured numbers with the defect marked, because a number
corrected by hand is not a measurement — but `build`'s two 44% cells each contain one
meaningless failure, and kimi's 7/9 contains one meaningless pass.

This is the third instance of one defect class in this spec: a needle that names what the
scenario is *about* rather than what the edit *writes*.

- **A2** asserted `sliceRange`, which sits on the unchanged signature above the edited line —
  false-failed six correct fixes until it was replaced with a `diff_excludes` on `lastIndex`.
- **A4** asserted `["divide", "ok"]`, both already present in its fixture baseline, so the
  gate passed regardless of what the model did (`seeded.ts:216` records the measurement).
  Read against changed lines it now means what its checklist means.
- **C2** asserts a filename.

Fix: gate on something the edit necessarily writes — `localhost:8080` or `fetch(` — and
re-run `build` in full, since a `--only` partial cannot replace a **current** scorecard cell.
Deferred rather than folded into the measuring commit: editing the spec marks both fresh runs
stale, and `stale` fails CI on `main` (`.github/workflows/ci.yml:90`).
