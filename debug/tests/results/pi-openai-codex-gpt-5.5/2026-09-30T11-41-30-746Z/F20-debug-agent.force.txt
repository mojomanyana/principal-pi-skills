Root cause: confirmed with measured evidence; `parse.mjs:1` uses `Number.parseInt(value, 10)`, which parses a leading integer prefix and ignores suffixes, and also does not enforce type, nonempty ASCII digits only, or safe integer constraints.
Fix: proved in disposable workspace only, not applied to caller — replace implementation with:
```js
export function parseCount(value) {
  if (typeof value !== 'string' || !/^[0-9]+$/.test(value)) {
    throw new TypeError('invalid count');
  }

  const count = Number(value);
  if (!Number.isSafeInteger(count)) {
    throw new TypeError('invalid count');
  }

  return count;
}
```
