# Test-quality review

The distinct [test-review skill](../../test-review/SKILL.md) owns test-quality judgment.
Load it for a material test-design question or explicit test review. One code reviewer may
use both skills and report their judgments separately; this is not a second independent
reviewer. A separately delegated test-review agent is optional, not another mandatory gate.
The skill defines observable oracles, focused wrong-implementation challenges, realistic
mocks, deterministic state checks and justified consolidation. It cannot grant integration
approval. Structural contract checks protect routing; regex presence alone does not
measure model compliance.
